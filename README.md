# 小米性能托盘

Windows 托盘工具：双击循环切换原厂性能档位，右键直接选档。绿色表示低功耗档，蓝色表示智能档，金色表示高性能档。

> **目前仅在 REDMI Book Pro 16 2026（Intel Core Ultra X7 358H，TM2425）上验证。欢迎其他机型反馈兼容情况；未经验证的机型不会默认开放切换。**

| 原厂供电资格 | 绿色 | 蓝色 | 金色 |
| --- | --- | --- | --- |
| 额定适配器 | 静谧 | 智能 | 狂暴 |
| 其他已确认条件 | 省电 | 智能 | 极速 |

供电资格不明确时只开放智能；原厂软件或机型不匹配时停止写入。它调用现有原厂服务，不另行设置 CPU 电压、功率限制、EC 或风扇曲线。

## 支持范围

本版本面向 **REDMI Book Pro 16 2026（Intel Core Ultra X7 358H），主板 TM2425**，支持已核验的小米电脑管家 **5.8.1.121／5.8.1.130**，MiService **4.1.1.648**。按原厂安装路径、程序及组件的版本资源和产品名核对，其他机型、未知版本或不匹配的组件不会放行切换。

**0.2.1 更新：修复管家升级到 5.8.1.130 后托盘变灰、不能切换的问题。** 新版性能通信路径经静态核对，三档切换又在本机真实验证。若以后管家再次更新到未经核验的版本，托盘会显示具体失败原因并暂停切换，需重新适配。

需要 Windows、.NET 10 Desktop Runtime，以及正在运行的原厂电脑管家、设备服务和智能调度服务。本项目不提供或重新分发厂商程序、驱动、DLL 或反编译源码。请从厂商渠道安装原厂组件。

## 使用

解压发布包后运行 `app/XiaomiPerformance.Tray.exe`，或右键 `Start-Tray.ps1` 选择“使用 PowerShell 运行”。双击托盘图标循环当前可用档位，右键选择指定档位。灰色代表状态暂不可确认。首次状态同步可能需要打开原厂电脑管家的“电池与性能”页面。

## Windows 节能模式关联（0.2.0）

需要登录自启时运行 `Enable-Autostart.ps1`；关闭自启运行 `Disable-Autostart.ps1`。移动程序目录后需重新运行开启脚本。自启只读取状态，不主动改档。

选择绿色档（省电或静谧）并确认原厂切换成功后，工具会请求开启 **Win+A 快捷设置中的 Windows“节能模式”**。它不是简单切换 Windows 电源计划。

切换到智能、极速或狂暴时，仅恢复本工具开启节能前保存的状态；如果原先已经开启节能，就继续保持开启。如果用户期间手动改变节能设置，工具尊重该变更，不盲目关掉节能。

Windows 节能开关写入使用未公开稳定契约的 WNF 接口，**本版本仅对 Windows build 28000 开放这条写入路径**，其他构建号不会强行调用。该限制独立于原厂档位的机型、版本及安装路径检测。若 Windows 节能关联失败，原厂档位切换与 Windows 节能结果必须分别确认。

2026-09-16 在上述机型、Windows build 28000、接电条件下实测：极速 → 省电时 Windows 节能开启，省电 → 智能时恢复关闭，再回极速不改节能状态；Windows 原生设置界面确认开关变化。静谧组的新节能联动及电池供电场景未在本次做实机复测，其他机型未经验证。

2026-10-13 在管家 5.8.1.130、电池供电条件下复测：极速 → 省电 → 智能 → 极速均收到原厂确认；Windows 节能原本已开启，整个循环保留原状态。65 项协议／控制器／节能／托盘事件检查和 9 项 CLI 模拟检查通过。此次未复测额定适配器的静谧／狂暴组。

联动只在本工具的选档／双击操作成功后执行；启动、定时刷新、`status` 和模拟都不写系统。通过原厂软件或快捷键改档，不会触发本工具自动联动。退出托盘不主动恢复节能，下次通过本工具切换蓝／金档时才尝试恢复；重启后不使用旧开机周期记录恢复设置。

命令行只读取状态：

```powershell
.\app\XiaomiPerformance.Cli.exe status --json
```

使用模拟状态，不调整设备：

```powershell
.\app\XiaomiPerformance.Cli.exe set eco --simulate --state-file .\simulation.json --json
```

## 从源码构建

源码位于 `src/`。需要 Windows x64 和 .NET 10 SDK；脚本不会安装 SDK 或原厂软件。

```powershell
pwsh -File .\scripts\Build.ps1
pwsh -File .\scripts\Test.ps1
pwsh -File .\scripts\Package.ps1 -Version 0.2.1
```

默认测试走模拟后端，不切换本机档位。自动测试通过不代表其他机型已通过实机验证。公开版本包含 C# CLI，无需 Python。

## 限制和问题反馈

原厂更新到未知版本后会停止切换，需要重新核验再适配。状态读取依赖原厂管家在当前运行期间发布的模式通知，未同步时不会猜测实际档位。

提交问题时请提供机型、系统版本、原厂软件版本及错误文字。不要上传原厂完整日志、设备序列号、账户信息或其他个人材料。本项目与小米无隶属关系，产品名称仅用于说明兼容性。

若提示“未完成的 Windows 节能联动记录”，程序会停止自动写入，原厂档位与 Windows 节能应分别查看。先退出托盘，并在 Windows 快捷设置中手动确认你要保留的节能状态；再将 `%LOCALAPPDATA%\XiaomiPerformance\energy-saver-link.json` 改名为 `.json.bak` 保留备份，重新启动。这样会放弃旧联动记录，以当前设置作为后续操作的基准；不要反复点击重试或随意编辑记录数值。
